# Bad Motherfucker

Samuel L. Jackson said it 171 times across 27 films (2014 HuffPost supercut, Ben Craw & Oliver Noble). Say it into your mic and try to match him.

Plain HTML/CSS/JS, no build step.

- **Counts:** `films.js`.
- **Voice:** the browser's Web Speech API. Works in Chrome, Edge and Safari, not Firefox. Needs https (or localhost) for mic access.
- **Test without a mic:** open with `?debug` and press space to add one.
- **Preview:** `python3 -m http.server` then http://localhost:8000.
- **Host:** any static host — GitHub Pages, Netlify, Cloudflare Pages.

Font: Rye (SIL Open Font License, see `fonts/`).
